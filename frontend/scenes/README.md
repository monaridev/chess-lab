# Cenários originais — Chess Lab V1.2

`school.svg`, `cozy.svg` e `stickers.svg` foram desenhados em SVG para este
projeto. Representam armários escolares, uma sala doméstica e recortes de
formas originais (gato abstrato, estrela e peixe). Não contêm personagens,
logos, screenshots, fontes remotas ou imagens incorporadas de terceiros.

A intenção de cores, ambiente e recortes vem da referência local
`docs/references/ref-gumball.png`; a imagem de referência não é servida pelo
frontend. Todos os elementos são decorativos e não alteram regras ou jogadas.
