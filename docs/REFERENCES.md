# Síntese

Queremos combinar:

**Chess Lab atual**
+ foco e seriedade de uma UI de xadrez
+ suavidade de cards pastel
+ mint/lavender/blush como detalhe
+ experiência acolhedora

Não queremos:

- dashboard genérico;
- neon gamer;
- interface infantil;
- cópia de Dribbble;
- redesign completo.
